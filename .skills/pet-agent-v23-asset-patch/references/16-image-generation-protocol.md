# 官方图片生成调用规范

本 Skill 的所有宠物视觉资产必须通过秒哒平台提供的「图片生成与编辑（超级版）」Skill 生成。该 Skill 是应用宠物唯一的正式图片生产能力，禁止自行调用任何非官方图片接口或脚本。

## 1. 调用前准备

### 1.1 必须已获得的用户确认

- 已完成应用分析。
- 已输出《应用宠物制作确认单》并等待用户回复。
- 用户明确回复“确认”“开始”“可以”“没问题”等肯定词。

未满足以上条件前，禁止调用本 Skill。

### 1.2 必须明确的输入

- 角色来源：用户参考图路径 或 文字描述。
- 应用画风参考：应用截图 / 现有插画路径 / 结构化 Application Visual System。
- 需要生成的资产清单（至少 canonical base + idle / working / success / remind 四种 Sprite Sheet）。

## 2. 调用方式

- 通过秒哒平台统一调用「图片生成与编辑（超级版）」Skill。
- 不要在指令或代码中硬编码英文 Skill ID、内部 API 路径、脚本路径或命令。
- 平台会自动匹配可用能力；如果平台未找到该能力，暂停并报告用户，不要改用其他方式生成。

### 2.1 生成 canonical base

**场景**：用户只有文字描述，或用户参考图需要风格化/卡通化。

**提示词必须包含**：

- 角色身份（物种、毛色/肤色、服装、标志性轮廓）。
- 稳定姿态（如 idle 坐姿、正面站姿）。
- 应用画风继承（参考应用视觉系统）。
- 简洁背景（`isolated on pure light background` 或 `clean white background`），便于后续去背景。
- 高质量、无文字、无水印、无 UI 元素。

**输出**：将生成的图片保存到 `tasks/` 目录，作为后续所有状态的唯一身份参考。

### 2.2 生成状态 Sprite Sheet

**场景**：以 canonical base 为唯一身份参考，生成某状态的 1×N 横向 Sprite Sheet。

**提示词必须包含**：

- 使用 canonical base 作为唯一角色身份参考。
- 状态语义（idle / working / success / remind 等）。
- 每帧动作描述，确保帧间连贯。
- 横向 1×N 布局，每帧等宽，角色居中。
- 继承应用画风。
- 角色主体大小、底部 anchor 与 canonical base 一致。
- 简洁背景，便于去背景。
- 无文字、无水印、无 UI 元素。

**输出**：每次生成保存到 `tasks/<state>-spritesheet.png`，禁止覆盖原图。

### 2.3 尺寸建议

- canonical base：建议 1024×1024 左右的方形尺寸，便于后续裁剪为透明 PNG。
- Sprite Sheet：根据单帧尺寸 × 帧数决定总宽度。例如单帧约 512×512、4 帧，总宽度约 2048。
- 实际尺寸由角色大小、帧数和应用环境共同决定，并在 `pet-sprites.json` 中记录真实值。

## 3. 输出与保存

- 将生成的图片保存到 `tasks/` 目录，作为源文件。
- 处理后的透明 PNG 保存到目标项目 `public/images/pet/`。
- 图生图时，**禁止覆盖原文件**；新文件名追加 `_v2`、`_edited` 或序号。

## 4. 失败处理

| 失败场景 | 处理方式 |
| --- | --- |
| 官方 Skill 调用失败（网络、配额、超时） | 重试一次；仍失败则暂停，向用户说明原因，不继续生成或接入。 |
| canonical base 不符合角色方向或应用画风 | 修正提示词、强化角色参考与画风继承后重试；仍无法修复则暂停并请求用户意见。 |
| 单个 Sprite Sheet 状态失败 | 仅重试该状态；必要时修改提示词；仍失败则暂停并报告。 |
| 多次重试后仍无法得到合格资产 | **停止宠物接入并报告**，不得改用 SVG、CSS、Emoji、图标、纯色圆点或临时占位角色。 |

## 5. 禁止行为

- 禁止用非官方图片生成能力（如自己调用其他文生图 API、用代码画图）生成宠物资产。
- 禁止用手写 SVG 角色、CSS 几何图形、Emoji、图标、纯色圆点、临时占位图替代正式图片资产。
- 禁止在图片生成失败后，声称“先用简单矢量角色顶上”或“做一个 SVG 版宠物”。
- 禁止将未通过 QA 的生成图片直接作为正式资产接入。
- 禁止将用户参考图或页面截图直接作为宠物 Sprite 使用（必须经过重新生成/风格化）。
