# 手机网站支付下单接口代码示例

> ⚠️ 页面跳转类 API（`alipay.trade.page.pay`）统一使用 `pageExec("alipay.trade.page.pay", "POST", ...)`，由 SDK 生成已签名的 HTML 表单。前端必须将返回的 `formHtml` 包装为 **Blob URL** 后跳转；禁止直接将长的签名 URL 赋给 `window.location.href`，也不要自行拼接或改写 SDK 生成的表单。

## 服务端（Edge Function）

```typescript
// supabase/functions/alipay-pay/index.ts
import { AlipaySdk } from "../_shared/alipay-sdk-deno.ts";

const sdk = new AlipaySdk({
  appId: Deno.env.get("ALIPAY_WEB_APP_ID")!,
  privateKey: Deno.env.get("ALIPAY_WEB_PRIVATE_KEY")!,
  alipayPublicKey: Deno.env.get("ALIPAY_WEB_PUBLIC_KEY")!,
  signType: "RSA2",});

Deno.serve(async (req) => {
  const { amount, subject, returnUrl, notifyUrl } = await req.json();

  const formHtml = await sdk.pageExec("alipay.trade.page.pay", "POST", {
    returnUrl,
    notifyUrl,
    bizContent: {
      out_trade_no: `ORDER${Date.now()}`,
      product_code: "FAST_INSTANT_TRADE_PAY",
      total_amount: Number(amount).toFixed(2),
      subject,
    },
  });

  return new Response(JSON.stringify({ formHtml }), {
    headers: { "Content-Type": "application/json" },
  });
}, isProduction);
```

## 前端（Blob URL 跳转）

```tsx
const { data } = await supabase.functions.invoke("alipay-pay", {
  body: {
    amount: "88.88",
    subject: "商品名称",
    returnUrl: `${window.location.origin}/success`,
    notifyUrl: `${import.meta.env.VITE_SUPABASE_URL}/functions/v1/alipay-notify`,
  },}, isProduction);

const blob = new Blob([data.formHtml], { type: "text/html;charset=utf-8" });
const blobUrl = URL.createObjectURL(blob);
window.location.href = blobUrl;
setTimeout(() => URL.revokeObjectURL(blobUrl), 5000);
```

## 异步通知验签（必须实现）

```typescript
// supabase/functions/alipay-notify/index.ts
import { AlipaySdk, verifySignatureV3 } from "../_shared/alipay-sdk-deno.ts";

Deno.serve(async (req) => {
    const body = await req.text();
    const params: Record<string, string> = {};
    for (const [k, v] of new URLSearchParams(body)) params[k] = v;

    const signStr = Object.keys(params)
        .filter((k) => k !== "sign" && k !== "sign_type" && params[k] !== "")
        .sort()
        .map((k) => `${k}=${params[k]}`)
        .join("&");

    const verified = await verifySignatureV3(
        signStr, params["sign"] ?? "", Deno.env.get("ALIPAY_WEB_PUBLIC_KEY")!
    );
    if (!verified) return new Response("fail", { status: 200 });

    // trade_status === 'TRADE_SUCCESS' || 'TRADE_FINISHED' 才更新订单为已支付
    // 同一 notify_id 需做幂等处理
    console.log("notify_type:", params["notify_type"], "out_trade_no:", params["out_trade_no"]);

    return new Response("success", { status: 200, headers: { "Content-Type": "text/plain" } });
});
```
