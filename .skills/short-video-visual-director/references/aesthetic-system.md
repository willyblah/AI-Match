# 视觉系统

选择一个主风格和最多一个辅助风格。风格名称是一组同时约束色彩、光线、材质、主体、构图和运动的预设。

| 风格家族 | 视觉读取 | 常用特征 |
|---|---|---|
| 空灵/神圣 | 轻盈、发光、柔和 | 云、光束、留白、慢推、漂浮粒子 |
| 超流行/Y2K | 光泽、霓虹、数码 | 铬、果冻质感、高饱和、快速爆发 |
| 暗黑/神秘 | 压迫、危险、颗粒 | 深黑、高反差、单点光源、手持 |
| 复古/印刷 | 平面、怀旧、图形化 | 半调网点、拼贴、旧广告、限制色板 |
| 有机/触感 | 亲密、自然、微观 | 织物、液体、皮肤、植物、微距 |
| 系统/数据 | 秩序、技术、抽象 | 网格、像素、热图、数字、示意图 |

## 视觉圣经字段

主/辅风格；基础色、强调色、危险色及比例；主光方向、硬度、色温和对比度；颗粒、锐度、眩光、色差与材质；景别、构图重心、负空间；镜头运动与速度；字幕层级、安全区与动效；允许转场、声音触发和禁用项。

## 原始 angelcore × cloud-trance 预设

需要还原原 `taste` 气质时使用：近黑与骨白为基底；暗场只用熔金/余烬暖光，亮场使用紫—青—品红晶体虹彩；一个镜头只保留一个强调色。暗场使用颗粒和轻微色差，亮场保持洁净光泽。镜头以漂浮、慢推、慢环绕为主，仅在高潮爆发速度。常用语法包括节拍硬切、黑底微距主体、强光闪白揭示、黑白中的单色突显和高潮前速度渐变。

该预设只是可选方向，不能覆盖用户已有品牌或参考。
