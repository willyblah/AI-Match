# 交易分析模板

当用户提供交易流水、账户汇总或预算数据时使用以下模板。

## 目录

- 数据归一化
- 分类体系
- 指标表
- 消费分析输出
- 月度财务报告
- 预算方案输出
- 债务偿还输出
- 异常交易识别
- 数据质量检查

## 数据归一化

预期的交易字段：

| 字段 | 含义 |
| --- | --- |
| 日期 | 交易日期。 |
| 描述 | 商户、对方账户或备注。 |
| 金额 | 正数或负数金额，需确认正负号约定。 |
| 类别 | 用户提供或推断的类别。 |
| 账户 | 可选，来源账户。 |
| 类型 | 收入、支出、转账、退款、债务还款、手续费、储蓄。 |

归一为以下类别：

- 收入。
- 必要支出。
- 可选支出。
- 储蓄与投资。
- 债务还款。
- 转账。
- 退款 / 报销。
- 未知。

## 异常交易识别

重点关注：

- 疑似重复的交易。
- 某类别突然激增。
- 异常大额消费。
- 新增订阅。
- 手续费、利息、透支与罚息。
- 被误记为收入的退款。
- 被误记为消费的转账。
- 信用卡还款与卡内明细重复计算。

异常应以"可能性"呈现，不作指控性表述。

## 数据质量检查

给出最终建议前先确认：

- 收入是否完整？
- 转账是否已排除？
- 退款处理是否正确？
- 信用卡还款是否被重复计算？
- 日期区间是否与用户需求一致？
- 类别是否前后一致？
- 一次性支出是否与周期性支出区分开？
