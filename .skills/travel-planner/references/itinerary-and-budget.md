# 行程与预算规范

## 行程规划

- 按地理区域分组，计算移动、排队、用餐和休息缓冲。
- 以用户节奏为准：轻松、适中或紧凑，不把活动数量当硬指标。
- 营业时间或预约条件未核实的项目标记为“待确认”。
- 使用目的地当地时间并显示时区。
- 为天气、交通延误和临时关闭提供替代方案。
- 适配儿童、老人、行动不便、饮食过敏和健康需求。
- 不把模板活动、餐厅或价格写成真实预订结果。

## 预算规则

- 默认比例只是可覆盖模板，不是当前市场事实。
- 同一币种内统计；没有带日期的汇率来源时，不跨币种合计。
- 报价显示币种、人数、单位、税费、服务费、退款条件和查询时间。
- 明确机票、住宿、税费、保险是否包含。
- 预算缓冲作为建议并说明原因，不给所有目的地固定百分比。

## 输出检查

- [ ] 日期和时区明确
- [ ] 交通和休息有缓冲
- [ ] 所有估算带币种和假设
- [ ] 没有跨币种无来源求和
- [ ] 事实、建议、估算、待确认项已分层
- [ ] 没有自动预订、支付或最低价格承诺
