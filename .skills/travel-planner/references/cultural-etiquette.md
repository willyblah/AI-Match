# 文化礼仪与场所规则研究模板

> 本文件是研究模板，不是国家、地区或宗教的固定事实库。

## 复核范围
必须指定国家、城市、具体场所、活动和查询日期。优先使用官方机构、场所公告和当地可靠来源。

## 研究维度

- 问候、称谓、排队、个人空间和沟通方式；
- 公共空间、商务场合、海滩和宗教场所的着装；
- 餐饮、饮食限制、服务费和小费；
- 宗教活动、开放对象、礼拜时间、鞋履、摄影和区域限制；
- 人物、博物馆、军警/政府设施和无人机摄影规则；
- 酒精、药物、处方药、公共行为、交通和其他法律限制；
- LGBTQ+ 安全和当地法律信息；
- 无障碍设施和场所辅助服务。

## 输出格式

```markdown
# [目的地] 礼仪与场所规则
查询日期：[YYYY-MM-DD]
适用范围：[国家/城市/具体场所]

## 已核实规则
- [规则] — 来源：[机构/页面] — 适用范围：[范围]

## 非强制习惯
- [习惯] — 来源：[来源] — 个体/地区差异：[说明]

## 待确认项
- [冲突、过期或未核实内容]
```

禁止按“整个亚洲/欧洲/中东”等区域做绝对结论；文化建议不能替代法律、健康或现场安全指引。具体场所现场要求优先于通用攻略。
