# 简历模板与输出样式参考（中文）

当用户需要结构化简历、简历骨架、ATS 友好模板、bullet 示例或求职信格式时使用这个参考文件。

## ATS 友好简历结构

```markdown
# [姓名]

[城市] | [邮箱] | [电话] | [LinkedIn] | [作品集 / GitHub]

## 个人简介

[2-4 行：目标岗位、年限 / 经验范围、最强领域、最强成果]

## 核心技能

- [技能组 1]：关键词
- [技能组 2]：关键词
- [技能组 3]：关键词

## 工作经历

### [公司名称] - [职位]
[起止时间] | [地点 / 远程]

- [动作 + 场景 + 方法 + 结果]
- [动作 + 协作对象 / 系统 + 影响]
- [动作 + 工具 / 流程 + 效率 / 收入 / 质量 / 用户结果]

## 项目经历

### [项目名称]

- [解决的问题]
- [你做了什么]
- [结果或收获]

## 教育背景

[学位] - [学校]

## 证书 / 论文 / 奖项

- [可选]
```

## 个人简介公式

### 产品 / 商业

`[岗位]，拥有 [年限 / 经验范围] 的 [领域] 经验。擅长 [优势 1]、[优势 2]，并能交付 [结果]。目标是 [目标岗位]，聚焦 [目标结果]。`

### 工程 / 数据

`[工程师 / 数据岗位]，具备 [系统 / 工具 / 领域] 经验。曾构建 [类型系统 / 分析]，提升 [性能 / 稳定性 / 成本 / 决策质量]。强项是 [技术能力]。`

### 运营 / 客服 / 支持

`[岗位]，擅长改善 [流程 / 客户 / 业务结果]。强项包括 [工作流]、[协作能力] 和 [成果 / 指标]。`

## bullet 改写公式库

### 结果型 bullet

`[动作] [项目 / 流程 / 系统]，为 [对象 / 范围] 带来 [指标 / 结果]。`

### 规模型 bullet

`在 [时间范围 / 业务范围] 内管理 [规模 / 数量 / 团队 / 流程]，提升 [质量 / 速度 / 成本 / 客户结果]。`

### 技术型 bullet

`使用 [技术 / 工具] 构建或优化 [系统 / 流程]，支持 [业务 / 用户结果]。`

### 领导力 bullet

`带领 [团队 / 利益相关方 / 工作流] 完成 [交付物]，协调 [相关方] 并实现 [结果]。`

### 指标不明确时的 bullet

`通过 [方法] 改善 [流程 / 结果]；如有基线、指标或业务结果，请补充。 [待核验指标]`

## 求职信结构

```markdown
尊敬的 [招聘团队 / 姓名]：

我对 [岗位名称] 很感兴趣，因为 [与公司 / 团队 / 产品相关的具体原因，必须结合 JD]。

在我最近的工作中，我曾 [证明点 1]。这与贵司对 [JD 需求] 的要求高度相关。我也曾 [证明点 2]，这将有助于 [公司 / 团队目标]。

我特别看重这个岗位的原因是 [具体动机]。期待有机会进一步交流，说明我的 [相关优势] 如何支持 [公司结果]。

此致
[姓名]
```

## 简历评审 rubric

| 维度 | 好的表现 |
|---|---|
| 目标匹配 | 简历能快速对应 JD 的重点 |
| 证据强度 | 所有关键主张都有结果、范围或细节支持 |
| 关键词 | 核心术语自然出现 |
| 可读性 | 招聘方可在 30 秒内扫到重点 |
| 真实性 | 没有未支持或夸大的内容 |
| 岗位层级 | 语言与目标岗位级别一致 |

## 核验清单

- 所有数字是否来自用户提供材料。
- 所有时间线是否完整且一致。
- 所有职位名称是否与原经历一致。
- 所有项目描述是否能被用户解释清楚。
- 是否存在过度包装、夸大或编造内容。
