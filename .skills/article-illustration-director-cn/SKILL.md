# 文章插图策划（国内秒哒版）

把中文文章中的核心判断、认知转折、流程、结构、状态和隐喻转化为少而有效的正文插图。插图必须帮助理解或记忆，不平均铺满文章，也不把正文改成PPT。

## 国内平台约束

- 本包只用于国内秒哒：界面、分析结果、错误提示、分镜和交付说明全部使用简体中文。
- 文章分析必须真实加载 `wenxin-text-generation`（展示名：`文本生成大模型`）。
- 生图或编辑必须真实加载 `image-generation-super`（展示名：`图片生成与编辑（超级版）`）；有参考图时走图片编辑能力。
- SKILL.md中的普通 `@名称` 不会自动绑定能力；生成应用的Query或平台配置必须加载真实Skill标签，生成轨迹应显示依赖。
- 仅在需要登录、跨设备、项目历史或团队协作时使用Supabase；按 `user_id` 开启RLS，媒体存Storage。

## 能力

1. **配图策略**：输出文章主旨、选点依据、插入位置和可编辑分镜，不生成图片。
2. **提示词包**：输出每张图的中文设计说明、稳定英文生图提示词和负面提示词。
3. **生成图片**：每张图独立提交并自动轮询；成功后必须显示真实图片、保存并下载，不能只显示任务ID。
4. **修改图片**：基于原图或人物参考进行编辑，保存新版本，不覆盖原图。
5. **角色系统**：从参考图提取脸型、发型、眼镜、服装、配色、物件、姿态与情绪锚点，保持整组一致。

## 工作流

1. 读取正文、Markdown、支持的文档、网页正文或截图，提炼主旨、认知转折、适合配图和不应配图的位置。
2. 不平均配图。优先选择核心判断、断点、输入输出、闭环、分流、前后对比、常见坑和状态变化。短文1–3张，普通文章4–8张，长文通常不超过9张。
3. 每张图只表达一个核心结构，记录插入位置、主题、核心意思、构图模式、人物动作、2–5个元素、1–4个短标注、提示词和16:9画幅。
4. 先建立全组共享的风格DNA和角色锚点，再设计单图变化。从当前文章发明隐喻，不复刻来源案例。
5. 用户要求生图时直接执行，每张图单独生成，不把整组拼成一张。
6. 完成 `提交 → 轮询 → 成功/失败/超时 → 预览 → 转存 → 下载`。刷新后恢复未完成任务；查询重试不得重复创建计费任务。
7. 生成后按 [质量检查](references/qa-checklist.md) 检查。局部文字、颜色或物件错误优先编辑；构图、隐喻或角色完全错误时重生成。

按需读取 [构图模式](references/composition-patterns.md)、[提示词模板](references/prompt-template.md)、[风格DNA](references/style-dna.md) 和 [国内应用规格](references/miaoda-app-spec.md)。

## 应用主链路

`粘贴/上传文章 → AI分析认知锚点 → 可编辑分镜 → 选择风格与角色 → 生成/编辑单张图片 → 预览与版本 → 下载/导出`

不得只生成介绍页、提示词表单、空画廊或任务ID展示页。创建任务只代表已提交；终态成功、图片可预览、已保存且下载可用后，才能显示“生成完成”。

## 默认视觉与来源

默认使用可配置的“文章观察员”：白色背景、深炭色线条、大量留白、低饱和水彩局部色、暗青蓝工具色、红橙风险色、少量短标注。用户品牌与参考图优先。`assets/source-observer-reference.png` 仅在用户明确选择来源预设时使用并保留来源说明。
