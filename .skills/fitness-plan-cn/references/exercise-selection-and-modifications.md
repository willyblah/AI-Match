# 动作选择与替代方案

按动作模式、器械、目标与限制条件挑选动作时使用本参考。优先选择用户能够安全且持续完成的动作。

## 动作模式

用以下模式搭建均衡方案：

- **深蹲**：以膝为主导的下肢动作。
- **髋铰链**：以髋为主导的下肢动作。
- **水平推**。
- **垂直推**。
- **水平拉**。
- **垂直拉**。
- **弓步或单腿**。
- **核心**：抗伸展、抗旋转、屈曲、负重行走。
- **移动或体能**。

并非每次训练都要覆盖所有模式，但整周应保持均衡。

## 动作清单

### 深蹲模式

初学者：

- 箱式深蹲。
- 高脚杯深蹲（goblet squat）。
- 坐起蹲（sit-to-stand）。
- 腿举。

中级／高级：

- 前蹲。
- 后蹲。
- 哈克深蹲。
- 保加利亚分腿蹲。
- 安全杠深蹲。

### 髋铰链模式

初学者：

- 髋铰链练习（动作模式训练）。
- 臀桥。
- 哑铃罗马尼亚硬拉。
- 壶铃硬拉。

中级／高级：

- 罗马尼亚硬拉。
- 六角杠硬拉。
- 传统或相扑硬拉。
- 臀推。
- 早安式屈体，仅限有经验者。

### 水平推

初学者：

- 上斜俯卧撑。
- 器械胸推。
- 哑铃卧推。

中级／高级：

- 俯卧撑。
- 杠铃卧推。
- 哑铃卧推。
- 绳索夹胸／推。

### 垂直推

初学者：

- 单臂杠铃推举（landmine press）。
- 坐姿哑铃推举。
- 器械肩推。

中级／高级：

- 站姿过头推举。
- 哑铃肩推。
- 阿诺德推举。
- 倒立式俯卧撑（pike push-up）。

### 水平拉

初学者：

- 坐姿绳索划船。
- 支撑式哑铃划船（胸部有支撑）。
- 弹力带划船。

中级／高级：

- 单臂哑铃划船。
- 杠铃划船。
- 器械划船。
- 反向划船（inverted row）。

### 垂直拉

初学者：

- 高位下拉。
- 助力引体向上。
- 弹力带下拉。

中级／高级：

- 引体向上（正握）。
- 引体向上（反握）。
- 负重引体向上。
- 跪姿绳索下拉。

### 单腿

初学者：

- 上台阶（step-up）。
- 后撤步弓步。
- 有支撑的分腿蹲。

中级／高级：

- 保加利亚分腿蹲。
- 行进弓步。
- 单腿罗马尼亚硬拉。
- 单腿蹲（pistol squat）渐进练习。

### 核心

初学者：

- 死虫式（dead bug）。
- 鸟狗式（bird dog）。
- 侧平板。
- 帕洛夫推（Pallof press）。

中级／高级：

- 各类平板变式。
- 悬垂举腿。
- 农夫行走。
- 腹肌轮。
- 绳索斜砍（cable chop）。

## 器械替代

| 缺少的动作 | 替代方案 |
| --- | --- |
| 杠铃深蹲 | 高脚杯深蹲、分腿蹲、腿举、控速徒手深蹲 |
| 硬拉 | 罗马尼亚硬拉、臀推、壶铃硬拉、臀桥 |
| 卧推 | 俯卧撑、哑铃推举、器械推胸、地板卧推 |
| 引体向上 | 高位下拉、助力引体、弹力带下拉、反向划船 |
| 绳索划船 | 弹力带划船、哑铃划船、器械划船 |
| 腿弯举 | 瑞士球腿弯举、滑板腿弯举、罗马尼亚硬拉 |
| 有氧器械 | 快走、爬楼梯、骑行、跳绳、低冲击循环训练 |

## 初学者默认配置

适用于新手或回归训练者：

- 全身训练，每周 2–3 天。
- 每次 4–6 个动作。
- 每个动作 2–3 组。
- 力量类动作 6–12 次。
- 辅助动作 8–15 次。
- RPE 6–8。
- 避免练到力竭。
- 动作安排保持 4–6 周不变。

## 居家训练选项

无器械：

- 深蹲或分腿蹲。
- 俯卧撑变式。
- 髋铰链或臀桥。
- 若有安全的支撑结构可做反向划船；否则仅在牢固前提下用毛巾划船。
- 平板、死虫式、侧平板。
- 上台阶、步行、爬楼梯。

弹力带：

- 弹力带划船。
- 弹力带下拉。
- 弹力带推举。
- 弹力带罗马尼亚硬拉。
- 弹力带侧向行走。
- 帕洛夫推。

哑铃：

- 高脚杯深蹲。
- 哑铃罗马尼亚硬拉。
- 哑铃推举。
- 单臂划船。
- 后撤步弓步。
- 农夫行走。

## 健身房训练选项

**固定器械**适用于：

- 初学者学习动作模式。
- 协调性要求较低的增肌训练。
- 绕开轻微限制进行训练。
- 稳定的渐进。

**自由重量**适用于：

- 力量技术。
- 协调性。
- 灵活的渐进方式。
- 复合动作训练。

尽可能两者结合使用。

## 疼痛规避改动

通用原则：

- **锐痛**：立即停止该动作。
- **组间逐渐加重的关节疼痛**：调整或停止。
- **肌肉发力感、轻微灼烧感或正常疲劳**：通常可以接受。
- **训练后持续疼痛**：降低训练量／强度，并考虑寻求专业评估。

膝关节敏感：

- 尝试箱式深蹲、控制幅度的腿举、上台阶、髋铰链、臀桥。
- 暂时降低下蹲深度或负荷。
- 避免会引起疼痛的跳跃或高冲击体能训练。

下背敏感：

- 尝试高脚杯深蹲、分腿蹲、臀推、胸部有支撑的划船、固定器械。
- 减少脊柱轴向负荷。
- 若疼痛加剧，避免大重量硬拉。
- 侧重核心支撑（bracing）与髋铰链模式的练习。

肩关节敏感：

- 尝试中立握哑铃推举、单臂杠铃推举、上斜俯卧撑、绳索划船。
- 避免引起疼痛的过头动作。
- 推与拉的训练量保持平衡。

腕关节敏感：

- 俯卧撑改用哑铃或把手支撑。
- 选择中立握姿。
- 若有疼痛，避免腕关节负重背屈的姿势。

## 有氧选项

低冲击：

- 步行。
- 骑行。
- 椭圆机。
- 游泳。
- 划船机（技术舒适的前提下）。

较高冲击：

- 跑步。
- 跳绳。
- 场地类球类运动。
- 间歇训练。

初学者、体重较大者、关节敏感或酸痛明显时，优先选择低冲击方式。

## 热身与放松

一般热身：

- 5–10 分钟轻松有氧或动态活动。

专项热身：

- 主项动作做 1–3 组更轻的递进组。
- 逐步增加幅度、负荷与发力意图。

放松：

- 轻松步行或骑行。
- 对已训练部位做温和拉伸。
- 若课次强度大，做呼吸降档调节。
