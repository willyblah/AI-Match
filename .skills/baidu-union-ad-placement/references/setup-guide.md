# 用户配置指南 — 百度联盟广告位接入

本 skill 属于**用户配置类**：使用前需要你在百度联盟后台创建广告位，并把**广告位 ID** 配置给应用。整个流程不涉及任何后端密钥。

## 一、获取广告位 ID

1. 登录百度联盟平台 [union.baidu.com](https://union.baidu.com/)。
2. 完成媒体（站点）的注册与审核，添加要投放广告的网站。
3. 在广告管理中**创建代码位（广告位）**，选择 PC 或 WAP 场景，设置广告尺寸、样式与拉伸规则。
4. 创建成功后，平台会给出该广告位的**广告位 ID**，形如 `u6341556`。
5. 记录这个广告位 ID，后续配置需要用到。

> 一个媒体下可以创建多个广告位，每个广告位有独立的广告位 ID。

## 二、配置环境变量

将获取到的广告位 ID 配置为环境变量：

| 配置项 | 环境变量 | 必填 | 说明 |
|--------|----------|------|------|
| 广告位 ID | `BAIDU_UNION_SLOT_ID` | 是 | 你的广告位 ID，如 `u6341556` |

> 广告容器的 class 名**无需配置**：生成投放代码时由模型自动生成唯一 class 或直接写死，只要与 push 的 `container` 一致、页面内唯一即可。

多个广告位时，可自行约定命名区分，例如 `BAIDU_UNION_SLOT_ID_HOME`、`BAIDU_UNION_SLOT_ID_ARTICLE`，并在生成投放代码时分别读取。

生成期读取示例：

```javascript
const slotId = process.env["BAIDU_UNION_SLOT_ID"];
if (!slotId) {
  throw new Error("未配置 BAIDU_UNION_SLOT_ID，请先在 union.baidu.com 创建广告位并配置广告位 ID");
}
// 容器 class 直接写死或生成，无需从环境变量读取
const container = "ad_slot_1";
```

## 三、安全边界说明

- **广告位 ID 是公开值**：它会直接出现在页面 HTML 的投放代码中，任何访问页面的用户都能看到，因此**不是机密信息**，无需像密钥那样保护。
- 本 skill **不需要任何私密密钥**，也不会调用需要鉴权的后端接口。
- 广告收益结算、反屏蔽域名、账户安全等由百度联盟后台管理，与前端投放代码无关。

## 四、前置条件校验

- 页面需通过 **http/https 协议 + 正常域名**访问；`localhost`、IP（如 `127.0.0.1`）、`file://` 下广告无法正常绘制。
- 若未配置 `BAIDU_UNION_SLOT_ID`，请勿使用占位假 ID 投放，应先完成广告位创建与配置。
