# 环境要求与常见问题自查

## 一、运行环境要求

- 广告投放页面必须通过 **http 或 https 协议 + 正常域名**访问。
- **不支持**以下访问方式（广告无法正常绘制）：
  - `localhost`
  - IP 地址（如 `127.0.0.1`）
  - `file://` 本地文件
- 本地构建测试环境时，请使用正常域名 + http/https 访问，广告才能正常绘制。

## 二、正式环境注意事项

- **浏览器环境**：按官方规范部署容器、投放代码与脚本即可。
- **PC 客户端 / webview**：本 skill 默认覆盖浏览器场景；若需在 PC 客户端 webview 内投放（涉及 cookie 留存、锁屏跳转默认浏览器等前置条件），需另行按平台要求申请与配置，不在本 skill 范围内。

## 三、拉伸规则

平台提供拉伸规则，让广告尺寸在不同场景下更适配页面（WAP / PC 各有可选规则）。按父容器拉伸时，广告宽度依据联盟广告容器外层容器宽度计算；需确保绘制时广告容器的宽高可正确获取。具体规则在联盟后台按广告位选配。

## 四、常见问题自查

### 展现类

1. **广告白屏**：检查容器 class 是否与 push 的 `container` 一致、容器宽高是否可正确获取、脚本是否成功加载。
2. **广告 logo 不展现**：检查投放代码是否完整、样式是否被页面 CSS 覆盖。
3. **某代码位长时间出现公益广告**：通常为该代码位暂无商业广告填充，可结合 `noAd` 兜底或联系联盟运营核实代码位状态。

### 请求报错

1. **请求报错 400**：自查该代码位的域名或计费名是否被封禁。
2. **请求报错 404**：自查投放代码、脚本地址是否正确，广告位 ID 是否有效。

### 反屏蔽相关（如涉及）

- 反屏蔽域名只有新增和修改逻辑，删除历史反屏蔽域名需联系运营人员。
- 反屏蔽域名证书可能续签失败导致广告请求不可用，需及时联系运营完成证书续签。
- 反屏蔽域名未生效时，通过平台查看未生效原因，判断自行解决还是联系运营处理。

> 说明：广告收益结算相关的异常（如结算数据核对）由百度联盟后台处理，本 skill 仅覆盖前端投放集成，不涉及任何结算金额或价格展示。
