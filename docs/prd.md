# 需求文档

## 1. 应用概述

### 1.1 应用名称
AI Match

### 1.2 应用描述
AI Match是一个现代化的AI工具智能推荐平台（Web应用，中文界面），通过数学建模方法为用户推荐最适合的AI工具或AI工具组合。系统基于熵权法-TOPSIS构建AI工具多维能力画像，结合用户手动设定的偏好权重，融合任务需求与成本约束，为用户提供个性化的Top 3推荐结果。

核心价值：用户仅需通过滑块直接设定7个维度的偏好权重并输入具体任务，系统即可自动计算匹配度并推荐最适合的AI工具，帮助用户在复杂的AI工具市场中快速找到符合自身需求与预算的最优方案。

## 2. 用户与使用场景

### 2.1 目标用户
- 轻度用户：偶尔使用AI工具，对成本敏感
- 普通员工：日常办公需要AI辅助，预算有限
- 软件开发者：高频使用代码生成与调试功能
- 企业团队：多部门协作，需要长上下文处理能力
- 研究人员：学术研究场景，注重推理与知识能力
- AI创业者：大规模调用，需要多模型编排能力

### 2.2 核心使用场景
用户访问平台 → 手动设定偏好权重（拖动滑块）→ 查看个人偏好画像 → 输入具体任务与预算 → 获得Top 3推荐结果 → 查看推荐理由与工具详情 → 横向对比多个工具 → 查看排行榜了解市场趋势

## 3. 页面结构与功能说明

│   └── 偏好画像页

│   └── 推荐结果页

└── 排行榜页
    └── 工具详情页

### 3.2 首页

**功能说明**
- 展示平台名称「AI Match」与核心价值主张
- 提供「开始测试」入口按钮，引导用户进入偏好设定页
- 展示平台核心功能介绍：实时数据更新、数学建模推荐、多维能力对比
- 提供「查看排行榜」快速入口

### 3.3 偏好设定页

**功能说明**
- 展示7个能力维度名称：编程能力、Agent能力、长上下文、知识推理、专业推理、成本价格、生成速度
- 每个维度提供滑块控件，用户通过拖动滑块直接设定该维度的偏好权重（数值范围0~100）
- 系统实时显示各维度当前设定的权重数值
- 系统自动将用户设定的权重归一化处理（总和为1）
- 提供「重置」按钮，恢复所有维度为默认权重（7维均为14.3）
- 提交设定后跳转至偏好画像页

### 3.4 偏好画像页

**功能说明**
- 展示用户设定的偏好权重结果，包括7个维度：编程能力、Agent能力、长上下文、知识推理、专业推理、成本价格、生成速度
- 使用雷达图或条形图可视化展示用户偏好权重分布
- 展示偏好画像描述文字（如：「您是成本敏感型用户，更看重价格与速度」）
- 提供「开始推荐」按钮，引导用户进入任务输入页

### 3.5 任务输入页

**功能说明**
- 用户选择或输入具体任务类型，系统提供预设任务模板：
  + 论文写作
  + 文献分析
  + 数据分析
  + Python编程
  + PPT制作
  + 图片生成
  + 视频生成
  + 信息检索
  + Agent自动化
  + 深度推理与代码工程
  + 长文本检索与文档解析
  + 自定义任务（用户可手动输入任务描述）
- 每个预设任务模板包含预设的7维需求向量r_jk（0~1），用户可选择性微调
- 用户输入预算约束（美元/月）
- 用户输入任务调用频率（次/月）
- 提交后，系统计算匹配度并跳转至推荐结果页

### 3.6 推荐结果页

**功能说明**
- 展示Top 3推荐结果，每个结果以卡片形式呈现，包含：
  + AI工具名称与版本
  + 匹配度百分比（0~100%）
  + 价格信息（输入价格、输出价格、单任务平均成本）
  + 7维能力雷达图（编程、Agent、长上下文、知识推理、专业推理、成本价格、生成速度）
  + 优势标签（如：「成本最优」「推理能力强」「速度快」）
  + 推荐理由（维度贡献分解，说明为什么推荐该工具）
- 每个卡片提供「查看详情」按钮，跳转至工具详情页
- 提供「横向对比」按钮，用户可选择2-4个工具进行对比
- 提供「重新测试」按钮，返回偏好设定页

### 3.7 工具详情页

**功能说明**
- 展示AI工具基本信息：名称、版本、研发公司
- 展示价格信息：输入价格、输出价格、完成Index所需token量、单任务平均成本
- 展示全部16项Benchmark指标数据：
  + 编程能力：Terminal-Bench、SciCode、LiveBench
  + Agent能力：GDPval-AA v2、τ3-Banking
  + 长上下文：AA-LCR
  + 知识推理：AA-Omni Accuracy、AA-Omni Non-Hallucination、Humanity's Last Exam
  + 专业推理：GPQA Diamond、Critpt
  + 成本价格：输入价格、输出价格、完成Index所需token量、单任务平均成本
  + 生成速度：API Speed (tokens/s)
- 展示7维能力雷达图
- 展示分维度能力贴近度（TOPSIS贴近度C_ik，0~1）
- 展示适用场景描述
- 展示数据来源与更新时间

### 3.8 横向对比页

**功能说明**
- 用户选择2-4个AI工具进行对比
- 展示对比雷达图（7维能力叠加显示）
- 展示对比表格，包含：
  + 基本信息（名称、版本、研发公司）
  + 价格信息（输入价格、输出价格、单任务平均成本）
  + 16项Benchmark指标数据
  + 7维能力贴近度
- 提供「返回推荐结果」按钮

### 3.9 排行榜页

**功能说明**
- 提供多种排行榜视图：
  + 综合排行（基于熵权-TOPSIS综合得分）
  + 按维度排行（编程能力、Agent能力、长上下文、知识推理、专业推理、成本价格、生成速度）
  + 性价比排行（综合能力/单任务平均成本）
- 每个排行榜展示AI工具列表，包含：
  + 排名
  + AI工具名称与版本
  + 得分或贴近度
  + 价格信息
- 点击工具名称跳转至工具详情页

## 4. 业务规则与逻辑

### 4.1 推荐算法逻辑

推荐算法必须严格遵循数学建模论文（文件位于 /workspace/app-dvtmyuucfs3l/tasks/26144.pdf，已提取文本 /workspace/app-dvtmyuucfs3l/tasks/pdf_content.txt）中的方法，具体步骤如下：

**步骤1：熵权-TOPSIS能力画像**
- 系统维护AI工具数据库，包含7个一级维度、16项二级Benchmark指标
- 7个一级维度：编程能力、Agent能力、长上下文、知识推理、专业推理、成本价格、生成速度
- 16项二级Benchmark指标：
  + 编程能力：Terminal-Bench、SciCode、LiveBench
  + Agent能力：GDPval-AA v2、τ3-Banking
  + 长上下文：AA-LCR
  + 知识推理：AA-Omni Accuracy、AA-Omni Non-Hallucination、Humanity's Last Exam
  + 专业推理：GPQA Diamond、Critpt
  + 成本价格：输入价格$/1M、输出价格$/1M、完成Index所需token量、单任务平均成本$
  + 生成速度：API Speed (tokens/s)
- 预处理：极小型指标（价格类）取倒数一致化，Z-score标准化
- 熵权法计算指标客观权重
- 分维度TOPSIS计算各模型7维能力贴近度C_ik∈[0,1]

**步骤2：用户偏好权重获取**
- 用户通过拖动滑块直接设定7个维度的偏好权重（数值范围0~100）
- 系统将用户设定的权重归一化处理，得到用户偏好权重w_k（总和为1）
- 归一化公式：w_k = 用户设定值_k / Σ(用户设定值_1~7)

**步骤3：效用函数计算**
- 用户输入任务后，系统根据任务类型确定任务需求向量r_jk（0~1）
- 计算效用函数：U_ij = Σ_k (w_k × r_jk × c_ik)
  + w_k：用户设定的偏好权重（归一化后）
  + r_jk：任务j对维度k的需求系数
  + c_ik：工具i在维度k的TOPSIS贴近度
- 匹配度归一化为0~100%

**步骤4：成本约束过滤**
- 计算单次调用成本：C_ij = Pin×Tin + Pout×Tout
  + Pin：输入价格$/1M
  + Pout：输出价格$/1M
  + Tin、Tout：任务平均输入输出token量
- 根据用户预算与调用频率，过滤或降权预算不足的方案

**步骤5：推荐结果生成**
- 按匹配度排序，输出Top 3推荐结果
- 生成推荐理由（维度贡献分解）

### 4.2 数据库设计

系统需设计以下数据表：

**ai_tools表**
- 字段：工具ID、工具名称、版本、研发公司、输入价格、输出价格、完成Index所需token量、单任务平均成本、API生成速度、数据更新时间

**benchmark_indicators表**
- 字段：工具ID、指标名称、指标值、指标类型（编程/Agent/长上下文/知识推理/专业推理/成本价格/生成速度）

**task_templates表**
- 字段：任务ID、任务名称、任务描述、7维需求向量r_jk（编程、Agent、长上下文、知识推理、专业推理、成本价格、生成速度）

**user_profiles表**
- 字段：用户ID、偏好权重w_k（7维）、创建时间

**topsis_scores表**
- 字段：工具ID、维度名称、TOPSIS贴近度C_ik、计算时间

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户未设定偏好权重直接进入任务输入页 | 系统提示用户先设定偏好权重，或使用默认权重（7维均为14.3） |
| 用户设定的所有维度权重均为0 | 系统提示用户至少设定一个维度的权重大于0，或使用默认权重 |
| 用户预算为0 | 系统仅推荐免费或成本最低的AI工具 |
| 用户预算不足以支持任何AI工具 | 系统提示用户调整预算或降低调用频率 |
| 用户输入自定义任务但未设置需求向量 | 系统使用默认需求向量（7维均为0.5） |
| 数据库中无符合条件的AI工具 | 系统提示暂无推荐结果，建议用户调整任务或预算 |
| 用户选择对比工具数量少于2个 | 系统提示至少选择2个工具进行对比 |
| 用户选择对比工具数量超过4个 | 系统提示最多选择4个工具进行对比 |

## 6. 验收标准

1. 用户访问首页，点击「开始测试」进入偏好设定页
2. 用户拖动7个维度的滑块设定偏好权重，提交后跳转至偏好画像页，展示偏好权重雷达图
3. 用户点击「开始推荐」进入任务输入页，选择预设任务模板（如「Python编程」），输入预算与调用频率，提交后跳转至推荐结果页
4. 推荐结果页展示Top 3推荐结果，每个结果包含匹配度百分比、价格信息、7维能力雷达图、优势标签、推荐理由
5. 用户点击某个推荐结果的「查看详情」，跳转至工具详情页，展示该工具的全部16项Benchmark指标数据与7维能力贴近度
6. 用户返回推荐结果页，点击「横向对比」，选择2个工具进行对比，展示对比雷达图与对比表格
7. 用户访问排行榜页，查看综合排行与按维度排行，点击某个工具名称跳转至工具详情页
