摘 要
随着大语言模型市场的快速扩张，模型数量激增、定价机制多样、能力维度
分化，用户在选择 AI 工具时面临难以兼顾能力匹配与成本控制的现实困境。针
对这一问题，本研究构建了一套通过客观能力评价再到主观场景适配和资源配
置优化的两阶段联合推荐框架。
在研究工作中，我们首先挑选了 6 款主流大语言模型，并从编程、Agent、
长上下文、知识推理、专业推理、成本价格与生成速度七个维度构建评价指标体
系，预处理后采用熵权-TOPSIS 方法计算各模型的分维度能力贴近度，形成客
观能力矩阵；随后针对六类典型用户群体，采用层次分析法确定各群体的场景化
偏好权重，将能力矩阵、任务需求与偏好权重融合为综合效用函数，并结合 API
调用成本与预算约束，以 0-1 整数规划求解全局最优的模型-任务分配方案。
研究结果表明，DeepSeekV4Pro在成本敏感型场景中占据绝对优势，Claude
Opus 4.8 在能力驱动型场景中表现突出，GPT-5.5 在学术研究场景中排名第一，
验证了多模型混合调用优于单一模型的资源配置规律。本文提出的框架将大语
言模型选型从经验驱动转化为数据驱动的组合优化决策，为不同用户群体提供
了可落地的选型与任务分配方案，具有良好的可扩展性与推广价值。
关键词：大语言模型、熵权-TOPSIS、AHP 层次分析法、0-1 整数规划

第一章 引言
1.1 研究背景
随着生成式人工智能的爆发式发展，大语言模型市场正经历前所未有的扩
张。从 GPT 系列、Claude 系列到 DeepSeek、Kimi、GLM 等国产大模型，各
类大语言模型在推理能力、代码生成、长文本处理、多模态理解等维度上形成了
差异化竞争格局。与此同时，各厂商推出了多样化的商业化购买方案，包括按
token 计费的 API 调用、订阅制套餐、免费额度与赠送 token 策略、企业批量折
扣等——使得定价机制日趋复杂，且价格调整频繁，市场呈现高度非平稳的动态
博弈特征。
图 1.1: 常见大模型
在此背景下，轻度用户、普通用户、软件开发者、学术研究者、企业团队及
AI 创业者等不同群体面临着日益突出的选择上的困难。不同用户的使用频率、
任务类型、预算约束与性能偏好存在显著差异：一名轻度用户可能仅需处理日常
问答，对成本高度敏感；而一名科研工作者则可能频繁调用长文本推理任务，更
看重模型的理解深度与上下文窗口，对价格敏感度相对较低。然而，现有研究及
第三方评测平台通常侧重于静态的模型性能排名或单一维度的性价比比较，对
于不同用户需求差异、实际应用场景变化以及多模型组合使用所带来的成本—
性能帕累托优化空间关注不足。
更为关键的是，大语言模型市场的价格与性能均随时间快速演化——新模
型不断发布、老模型持续降价、免费额度定期更新——静态评估结果往往在短期
内即失去参考价值。因此，用户需要一种能够结合自身需求特征、适应模型市场
变化，并支持多产品组合选择的动态推荐框架，从而在能力、价格与速度之间实
现更合理的权衡。

1.2 相关研究综述
1.2.1 大语言模型评测相关研究
大语言模型评测是模型选择与应用的基础。现有研究主要围绕模型能力、安
全性与可靠性等维度展开。Huzhi Xue 等人针对传统评测体系覆盖有限、评价维
度单一的问题，构建了涵盖偏差、服从性与鲁棒性等六项指标的综合评估框架，
实现了模型性能的量化排序 [1]。然而，该研究在一定程度上依赖人工标注，存
在较强主观性，且未纳入调用成本、速率限制及上下文容量等实际使用因素，导
致评估结果与用户真实选型需求之间仍存在差距。
1.2.2 大语言模型定价与成本优化相关研究
随着大语言模型商业化程度不断提高，其定价机制逐渐成为研究热点。Zhong
从信息设计视角分析了基于用户时间敏感性的最优定价策略 [2]；Bergemann 等
从合同理论角度构建了 token 用量分层定价框架 [3]；Mahmood 则从市场竞争角
度揭示了先发者与后发者在成本效益上的博弈关系 [4]。现有研究从平台收益优
化、合同设计与竞争机制等角度系统分析了 LLM 定价问题，但多数研究仍主要
面向服务提供商视角，缺乏从用户资源配置角度进行综合成本建模的研究。
1.2.3 大语言模型推荐与资源分配相关研究
近年来，大语言模型推荐与资源分配逐渐受到关注。Lingjiao Chen 等提出
了多模型级联调用框架，以降低整体推理成本 [5]；Ong 等进一步实现了提示词
级别的动态路由，提高了模型选择效率 [6]。然而，现有方法大多建立在需求规
模、预算约束和调用成本完全确定的静态假设之上，未充分考虑用户 token 消耗
波动、免费额度到期及预算超支风险等不确定因素。因此，在多场景、多约束条
件下的大模型全局资源优化配置问题仍有待进一步研究。
然而，现有研究在多维评价指标融合与用户异质性建模方面仍存在割裂，尚
未形成面向真实使用场景的统一决策框架。基于此，本文拟构建面向多场景用户
需求的大语言模型综合评价体系，并进一步建立考虑不确定性的个性化推荐优
化模型，以实现能力—成本—效率之间的协同最优。
1.3 研究意义与创新点
1.3.1 研究意义
• 理论意义：现有研究多将大语言模型选择简化为性能排名问题，本文将其
重新定义为预算约束下的多目标组合优化，体现了模型能力差异与用户任
务需求之间的匹配关系，并验证了多模型混合调用在资源配置上优于单一
模型的规律。

• 模型意义：本文将熵权-TOPSIS、AHP 与 0-1 整数规划整合为多层建模框
架，使推荐逻辑从“哪个模型最好”转变为“在预算内如何组合模型最合

• 现实意义：面对模型种类繁多、定价复杂、能力参差不齐的市场现状，普
通用户的选型成本正在快速上升。本研究提供了一套从能力评价到个性化
推荐的完整方法，帮助不同背景的用户找到真正适合自己场景的模型组合
方案。
1.3.2 创新点
• 构建多维能力评价体系
本文使用 TOPSIS 方法建立模型能力评价矩阵，从七个不同方面分析模型
能力，并根据不同任务的需求选择更合适的模型。
• 融合能力评价、用户偏好与资源优化
我们将模型能力评价、用户偏好分析和资源分配放在同一个框架中，分析
不同模型特点与用户需求之间的关系，并通过优化方法解决模型选择问题。
• 面向多类用户构建场景化个性推荐机制
此研究针对六类常见用户，分别分析他们对模型的不同需求，并计算对应
的指标权重，从而让模型推荐过程能够根据用户特点进行调整。

2.2 基本假设
为保证模型构建与求解过程具有可行性，并在一定程度上降低现实环境中
复杂因素对研究的干扰，本文结合大语言模型市场特征及用户使用行为，提出以
下基本假设：
• 评价有效性假设
假设各公开 Benchmark 测试结果在一定程度上能够反映大语言模型的相
对能力水平，并在研究周期内保持可比性，且评测标准在研究周期内保持
一致，不存在显著的外部扰动。
• 用户需求稳定性假设
假设用户在一定决策周期内的任务类型、使用频率及预算约束相对稳定，
可抽象为若干具有代表性的典型用户画像，且各画像在研究窗口内的核心
需求任务偏好以及预算约束结构保持相对稳定，从而便于进行需求建模与
个性化推荐分析。
• 成本可加性假设
假设用户使用大语言模型所产生的总成本由 API 调用成本、订阅成本及隐
性时间成本线性叠加构成，各项成本之间相互独立，不考虑复杂的交叉补
贴或动态折扣机制。
• 市场短期稳定性假设
假设研究周期内各模型的定价策略、性能水平及用户偏好变化具有短期稳
定性，不发生大规模结构性调整，从而保证基于历史数据构建的推荐模型
具有现实参考意义。
• 场景独立性假设
假设不同用户场景之间的需求偏好相互独立，各场景下模型效用可单独评
估，并通过统一优化框架进行资源配置。
• 任务需求独立且可分假设
假设同一用户的多个任务（如代码生成、文档摘要、日常问答等）在能力
需求上相互独立，可分别分配给不同模型执行，且各任务对模型的能力诉
求不产生相互干扰。该假设确保总成本函数具有可加性，便于采用线性规
划方法求解最优分配方案。
• 预算硬约束假设
假设用户月度预算是不可突破的刚性上限。即用户在模型选择过程中必须
严格满足成本约束条件，推荐方案的总成本不得超过用户预算。该假设保
证推荐结果在实际使用中具备财务可行性，真实反映用户的支付能力限制。

5.1 总结
本文针对大语言模型市场快速扩张时用户选型困难的问题，构建了一套融
合能力评价、场景适配与资源分配的个性化推荐框架。研究选取六款主流大语言
模型，从七个维度构建评价指标体系，基于熵权-TOPSIS 方法计算各模型分维
度能力，揭示了模型之间显著的差异化能力结构：GPT-5.5 在编程、长上下文与
专业推理上全面领先，Claude Opus 4.8 在知识推理与 Agent 能力上表现突出，
而 DeepSeek V4 Pro 在成本价格维度上具有绝对优势。
在此基础上，研究通过层次分析法对六类典型用户群体进行偏好建模，发现
不同群体的核心诉求差异显著：轻度用户注重降低成本，软件开发者高度侧重编
程能力，企业团队最看重长上下文处理，研究人员则优先关注推理与知识能力。
将主观偏好权重与客观能力矩阵、任务需求相结合，进一步构建 0-1 整数规划模
型，在预算硬约束下求解全局最优的模型-任务分配方案。
推荐结果表明：预算受限场景下，DeepSeek V4 Pro 凭借其成本优势成为
轻度用户和普通员工的主力模型；中高预算场景中，Claude Opus 4.8 和 GPT-
5.5 因其突出的核心能力被优先分配给高价值任务；高预算场景下则倾向于采用
Claude 作为统一主力模型以降低工程复杂性。整体而言，模型揭示了大语言模
型选型的本质——并非单纯的模型优劣排序，而是模型能力异质性与用户偏好
差异共同驱动下的多目标组合优化问题。
5.2 模型优缺点
在模型构建和分析过程中，我们也发现了一些优点和不足之处。
5.2.1 模型优点
1. 方法组合严谨：将熵权法-TOPSIS 客观评价与 AHP 主观赋权结合，形成
从数据驱动到用户偏好的完整量化链条。
2. 决策逻辑清晰：通过 0-1 整数规划将效用最大化与预算硬约束统一在同一
框架内，各变量、目标函数与约束条件的制衡关系明确，可求解全局精确
最优解。
3. 适配灵活性强：AHP 权重、任务需求矩阵及预算上限均可根据不同用户场
景独立调整，能覆盖从轻度用户到 AI 创业者等多类典型群体。
5.2.2 模型缺点
1. 模型假设可能与现实存在偏差。实际上 token 消耗量随上下文和参数显著
波动，成本测算基于固定常数可能使推荐方案在实际调用中超出预算约束。

5.3 展望

当前框架未纳入多模态信息处理能力的问题，可进一步扩展多模态大模型能力
刻画与评价维度，将图像与文本等异构信息纳入统一评估体系，以增强模型选型
方法在复杂应用场景中的适用性。

# 定义核心函数
def calculate_weights(matrix):
”””计算判断矩阵的权重向量”””
lamb, v = np.linalg.eig(matrix)
lambda_max = np.max(np.abs(lamb))
loc = np.argmax(np.abs(lamb))
weights = v[:, loc]
weights = np.real(weights) / np.sum(np.real(weights))
weights = np.round(weights, 4)
return weights, lambda_max
def calculate_consistency(matrix, weights, lambda_max):
”””计算一致性比率CR”””
n = len(matrix)
CI = (lambda_max - n) / (n - 1)
RI_dict = {1: 0.00, 2: 0.00, 3: 0.58, 4: 0.90, 5: 1.12,
6: 1.24, 7: 1.32, 8: 1.41, 9: 1.45, 10: 1.49}
RI = RI_dict.get(n, 1.5)
if RI == 0:
CR = 0.0
else:
CR = CI / RI
return CR

import numpy as np
import pulp
def solve_allocation_model(utility_matrix, cost_matrix, frequencies, budget_b):
”””
求解资源配置 0-1 整数规划模型
:param utility_matrix: 综合效用矩阵 U (N x M)
:param cost_matrix: 调用成本矩阵 C (N x M)
:param frequencies: 任务调用频次 f (M)
:param budget_b: 总预算约束 B
”””
N, M = utility_matrix.shape
prob = pulp.LpProblem(”LLM_Resource_Allocation”, pulp.LpMaximize)
# 1. 定义决策变量 x_{ij}
x = pulp.LpVariable.dicts(”x”, (range(N), range(M)), cat=pulp.LpBinary)
# 2. 目标函数: 最大化总效用
prob += pulp.lpSum([utility_matrix[i][j] * x[i][j] for i in range(N) for j in
range(M)])
# 3. 约束条件: 任务唯一分配
for j in range(M):
prob += pulp.lpSum([x[i][j] for i in range(N)]) == 1
# 4. 约束条件: 预算硬约束
prob += pulp.lpSum([cost_matrix[i][j] * frequencies[j] * x[i][j]
for i in range(N) for j in range(M)]) <= budget_b
# 求解
prob.solve(pulp.PULP_CBC_CMD(msg=0))
# 提取结果矩阵
result_x = np.array([[pulp.value(x[i][j]) for j in range(M)] for i in range(N)])
return result_x
